# Krafton Jungle · Game Tech Lab

**강명호 · [DDing-Ho](https://github.com/DDing-Ho)**의 크래프톤 정글 Game Tech Lab 3기 학습·팀 프로젝트 목차입니다.

**1~14주차와 5+주차 · 주차별 문서 15개 · 원본 저장소 17개**

DirectX 게임 제작에서 출발해 자체 3D 엔진·에디터, 렌더링, 애니메이션, 파티클과 물리 기능을 개발하고 게임잼 결과물로 연결한 과정을 정리했습니다.

## 원본과 기여를 읽는 방법

- 이 저장소는 주차별 문서와 원본 링크를 모은 목차입니다. 원본 저장소의 코드·브랜치·커밋·이슈·PR·공개 범위는 그대로 유지합니다.
- 원본은 팀 공동 결과물입니다. 각 문서의 **내 기여**에는 `DDing-Ho`가 작성한 기능·수정 커밋을 연결했습니다.
- 주차별 제목은 원본 문서와 작업 이력을 요약한 정리 주제입니다.
- **5+주차**는 CaptainTangerine와 mathison0의 원본을 모두 연결했습니다.
- **10주차**는 후속 작업이 확인되는 kim-kihoon 팀 저장소와 DDing-Ho의 초기 작업 저장소를 함께 연결했습니다.
- 비공개 원본은 접근 권한이 필요합니다. 이 공개 목차에는 과제 코드·에셋을 복사하지 않았습니다.
